# HelloBlockchain Project

這是一個基於以太坊的智能合約專案，實現了一個簡單的「請求-回應」系統，任何人都可以在區塊鏈上發送請求與回應訊息。專案使用 **Solidity**、**Truffle** 和 **Ganache** 進行開發與測試。

---

## ⚙️ 開發環境

- Node.js ≥ 14
- Truffle ≥ 5.0
- Ganache（本地測試鏈）  
- Solidity 0.8.x  

---

## 🚀 執行流程

```bash
npm install
truffle develop
truffle compile
truffle migrate --reset
truffle test
truffle exec scripts/store.js
```
